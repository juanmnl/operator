# Operator UI/UX audit — 2026-10-01

Report only. No code was changed. Author: Design lane.

## How this was done

**Live, in the running dev instance** (Vite :1422, CDP :9340, isolated `OPERATOR_DIR`; it already held 4 projects whose folders are under the non-existent `/Users/dev/`). I drove it over CDP with Playwright `connectOverCDP`, took screenshots, read the accessibility tree, ran a WCAG contrast probe over every visible text node, walked the Tab order, and emulated narrow widths with `Emulation.setDeviceMetricsOverride`.

- Surfaces checked live: worktree overview, project gallery, Agents (Fleet + Subagent library), Tuning (loading + loaded), command palette, project workspace (Board, Team, Moodboard), the "folder not on disk" error state, Operator preferences, Global settings.
- Themes checked live: Mission Control dark and light on every surface above; Mr Pink light and 1984 light on Board and Team.
- Widths checked live: 1100×720 (default), 760×600, 560×600.
- States checked live: empty (no agents, no tasks, no worktrees, empty moodboard, empty library), loading (Tuning), error (missing project folder).

**Not checked live**, because they need a running agent, a served page or a destructive click: terminal panes with a real lane, the Preview tab with a page loaded, the Electron preview source, toasts, the quit dialog, diff/merge surfaces, a populated board. These are covered by the code-side audit only (appendices), and I list them so nobody reads this as GUI-verified.

**Code-side**: five read-only agents audited the renderer by surface against the same checklist (project rules R1/R2/R3, tokens, accessibility, states, copy). Each was told to verify every line number. I spot-checked 12 of their high findings against the source (two of them live) and all 12 held. Their findings are in Appendices A–E, lightly edited. Where an appendix proposed a fix that contradicts a house rule, I replaced it and marked the change "(Design override)".

House rules applied: R1 no `opacity` on `--fg-muted` text (and no group-opacity recede); R2 two verbs never share a glyph, and the guard is proportional to the damage; R3 no orphaned first word after a full stop in display copy (also no single-word last line). Also the 2026-07-28 ruling: a control's label is body text (4.5:1), meta text may sit at 3:1.

Totals across this report: about 35 high, 165 medium, 215 low. The appendices overlap in places (the same `styles.css` rule reached from two components), so the true count of distinct defects is somewhat lower.

## Top 5

1. **Keyboard focus is invisible almost everywhere** (high). The renderer has 151 `outline: none` declarations and 9 `:focus-visible` rules. Live Tab walk on the project page: of 17 tab stops, 4 showed any indicator (plan meter, "Show 4 more controls", sidebar toggle, the assignee `<select>`). The rail header, Home, rail foot, Board/Team/Moodboard tabs, "Resume 4 agents" and the task composer show nothing. `.sidebar-project-home:focus-visible` in `styles.css:42-56` is dead CSS: no element carries that class any more. Hover-revealed controls make it worse: the gallery card's `⋯` stays at `opacity: 0` while focused (measured live), and pressing Enter on it opens the project instead of the menu (`ProjectGallery.tsx:447`), so Forget/Shelve are unreachable by keyboard. **Fix:** one global rule in `styles.css`: `:where(button, a, input, textarea, select, [role="button"], [role="tab"], [tabindex]):focus-visible { box-shadow: inset 0 0 0 1px var(--accent); }`, then delete the per-element `outline: 'none'` lines over time; reveal hover-only controls on `:focus-visible` / `:focus-within` (the existing `.tb-card:focus-within .tb-del` pattern, `styles.css:800`); guard card `onKeyDown` with `if (e.target !== e.currentTarget) return`.

2. **Destructive actions without a proportional guard (R2)** (high). ⌘W and the palette's "Close this session" end a running lane mid-turn with no confirm, drop its saved record so Resume is no longer offered, and remove its worktree after a WIP commit (`DashboardView.tsx:4504-4513`, `5114`). The rail's "Close project" does confirm, so the narrower action has the weaker guard. On the Done card, `↩` means requeue (`TaskBoard.tsx:932`) while the diff card drawn under it labels merge `Merge ↩` (`TaskDiffCard.tsx:83`): one glyph, two verbs, and one of them writes to the base branch. The Subagent library's Delete removes the agent `.md` with no confirm (`AgentLibraryView.tsx:134-140`). **Fix:** ⌘W on a working or asking lane arms first ("⌘W again to end Code — it is mid-turn"), idle lanes close directly; drop the glyph from the merge button (`Merge into main`); arm-then-confirm on library Delete, naming the file.

3. **A project whose folder is gone still offers every action** (high, verified live). The banner says "This project's folder is not on disk." and gives no way out (`ProjectView.tsx:283-293`), while the header still offers "Resume 4 agents" (`ProjectView.tsx:141-155`), the board offers a task composer, and Team offers to add lanes. Team also says "No agents yet." directly under "Resume 4 agents": the four saved sessions are not shown anywhere on the page. **Fix:** give the banner two actions, "Locate folder…" and "Remove from Operator"; hide Resume and disable the composer while the folder is missing, with the reason in the disabled control's title; on Team, list saved sessions as "4 saved sessions · Resume" instead of the empty-roster copy.

4. **Escape is swallowed app-wide after "Open scratch terminal"** (high, verified live). The palette offers "Open scratch terminal" on every screen (`DashboardView.tsx:5142`), but the sheet only renders in a session view (`6007`). Run from Settings, it does nothing visible and leaves `shellOpen = true`, which arms a window-level capture listener that eats the next Escape (`4541-4552`). Measured: with the palette open, the first Escape did not close it; the second did. With the sheet genuinely open, the same listener keeps Escape from vim/less in the shell and from the palette and dialogs. **Fix:** list the command only when a session view is active (or switch to it first); attach the Escape handler to the sheet's own container, and only act when focus is inside it.

5. **Narrow windows break the project header** (high, verified live). The sidebar keeps about 270px at every width. At 760px the project name truncates to "oper…" and "RESUME 4 AGENTS" wraps onto two lines. At 560px the project name collapses to zero width, the Moodboard tab and the Resume button render past the right edge (their right edges at 563px and 642px in a 560px viewport, so Resume cannot be clicked), and the test-command input on Team collapses to a 20px box. **Fix:** collapse the sidebar to the icon rail automatically below a content width of about 720px; in the project header give the name `minWidth: 80` with ellipsis, give Resume `whiteSpace: 'nowrap'` and let it drop to an icon-plus-count below 640px; let the Team toolbar wrap (`flexWrap: 'wrap'`) so the test-command field keeps `minWidth: 220`.

Next in line: raw `--accent` as small text fails on two light palettes (2.44:1 on 1984 light for the active project tab); R1 opacity on `--fg-muted` in at least 9 places, including the session footer path on every session view; toasts truncate their detail line before the part that matters; ⌘E is dead while the palette advertises it; a failed worktree creation silently runs the lane in the main checkout.

## Cross-cutting themes

These repeat across surfaces. Fixing each at the token or shared-style level removes most of the per-file findings in the appendices.

- **Focus.** See Top 5 #1. One global `:focus-visible` rule, plus reveal-on-focus for every hover-only control (gallery `⋯`, "+ Add a description", Restore, roster Configure `▾`, rail `⋯` which uses `display: none` and cannot be focused at all, moodboard remove).
- **Accent used as text.** Raw `var(--accent)` as small text measures 2.92:1 on Mission Control light and 2.44:1 on 1984 light (live). It appears in the project tabs, the dev-server toggle, Comms, link buttons in Settings, the Install button. `styles.css:769` already has the recipe (`color-mix(in srgb, var(--accent), var(--fg) var(--lane-ink-blend, 0%))`); export it as an `--accent-ink` token per palette and use it wherever accent is drawn as text.
- **R1 opacity stacked on `--fg-muted`.** Found in `styles.css:469` (session footer path), `styles.css:146` (queued activity rows), `SessionItem.tsx:297` (rail phase word, 0.65), `ActivityDashboard.tsx:146,154` (0.5), `RecentLists.tsx:29` (0.5 at 9px), `AgentLibraryView.tsx:480` (0.7, measured 3.63:1 dark and 2.65:1 light), `AppPreviewPanel.tsx:1112` (0.7), the session toolbar branch chip (0.82 × 0.8), plus dead Chat CSS in `styles.css:491-671`. Delete the opacity in each case.
- **Control labels drawn in `--fg-muted` on light palettes.** Live: rail foot labels 3.80–4.18:1, back chip 3.74:1, composer "Add" and "Unassigned" 3.73:1 on Mr Pink light, model/effort labels on preset cards 3.73–3.86:1. Under the 2026-07-28 ruling these are body text. **Fix:** `color-mix(in srgb, var(--fg) 72%, transparent)` for control labels; leave `--fg-muted` itself alone (Design override of Appendix D's proposal to darken it, which the same ruling rejects because it would brighten every meta label).
- **Colour-only state.** Selected tab in the project header, Tuning period buttons, Preview mode toggles and status orbs in the collapsed rail carry state by colour only, and none expose `aria-selected` / `aria-pressed`. Add the ARIA attribute and a non-colour marker (the 1px underline the Settings tabs already use).
- **Three tab styles.** Project header: mono uppercase, accent text, no underline. Settings and Agents: sentence case with accent underline. Tuning: bordered segmented buttons. Pick the Settings style for page tabs and the segmented style for value pickers, and give both `role="tablist"`/`role="tab"` or `aria-pressed`.
- **Terminology.** One seat is called agent, lane, role and session, sometimes in one sentence: "Assign it to an agent now, or leave it for whichever lane picks it up" (board), "Add an agent" (rail) next to "+ Blank lane" (Team), "No agents yet. An agent is a lane: …". Pick "agent" for the user-facing noun and keep "lane" for internals and charters, or define "lane" once and use only it.
- **Dynamic border colour on radiused elements** (the known WKWebView freeze cause) remains in theme cards, dock-icon cards, keep-warm options, the Tuning card, footer buttons and `.tb-*` hover. Move the state to `box-shadow` or background.

### Left rail (ProjectRail, foot-cell)
