# Diff tab: wrap long lines — 2026-09-16

Lane: Design. Branch `operator/666300`. Commit: `800b204`.

## Cause

`DiffLine` in `src/renderer/components/session/DiffBody.tsx` gave every row `white-space: pre`. A
line longer than the panel made the scroll container's content wider than the panel, but each row
and each sticky file header was a block the width of the panel. Scrolling sideways showed text past
that width with no row background behind it, and the file header cut off at the first screen width.

## Scope

`DiffPanel.tsx`, `CanvasDiffPanel.tsx` and `TaskDiffCard.tsx` all render `<DiffBody>`, and none of
them has its own row styling or `white-space` rule. One change fixes all three.

## Change

- **Row layout.** A row with a marker is a CSS grid, `1ch | minmax(0, 1fr)`:
  - Column 1 is the `+`, `-` or space, `white-space: pre`.
  - Column 2 is the text, `white-space: pre-wrap; overflow-wrap: anywhere; min-width: 0`.
  - Continuation lines start in column 2, which gives the hanging indent. The `+`/`-` column stays
    straight down the file, and one logical line reads as one line.
- **Tabs and indentation** are kept by `pre-wrap`. `tab-size` is unchanged.
- **Unbroken runs** (URLs, long tokens, base64) break at any character because of `overflow-wrap: anywhere`.
- **Hunk headers and git notes** (`@@ … @@`, `\ No newline at end of file`, `Binary files … differ`)
  have no marker. They wrap from the row's own padding.
- **Backgrounds** are on the row, which is always exactly the panel width, so the add/del tint and the
  hunk tint cover every wrapped line.
- **Scroll container:** `overflow-x: hidden; overflow-y: auto; min-width: 0`. Nothing inside is wider than
  the panel any more, so the sticky file header (`width: 100%`) spans the whole visible width.
- Colours are the same tokens as before (`--add-fg/--add-bg`, `--del-fg/--del-bg`, the accent 8% hunk
  tint, context at the 60% `--fg` mix), now in `INK`/`GROUND` maps keyed by line kind.
- This diff view has no line numbers, so there was no line-number column to align.

## Pure helper

`splitDiffLine(line) → { kind: 'hunk'|'add'|'del'|'context'|'meta', marker, text }`, exported from
`DiffBody.tsx`. Tests in `diff-parse.test.ts`:
- `+`, `-` and space split into a marker and the text.
- Tabs and leading spaces are kept exactly.
- `--- dashes` and `+++ pluses` inside a hunk read as content, the same as `parseDiff`.
- Hunk headers and git notes have no marker.
- An empty line reads as blank context.
- Every line of the real `git diff` fixture rebuilds from `marker + text` with no character lost.
