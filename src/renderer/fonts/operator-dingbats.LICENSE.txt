operator-legacy.woff2 is a subset of GNU Unifont (unifont_upper, v16.0.04).

It contains only the "Symbols for Legacy Computing" (U+1FB00–1FBFF) and "Symbols for
Legacy Computing Supplement" (U+1CC00–1CEBF) block-mosaic glyphs, with advance widths
normalised to a single monospace cell, used as a monochrome fallback so the terminal can
render the block-mosaic characters in Claude Code's logo/art (e.g. U+1FB82, U+1FB90,
U+1FBE0, U+1FBF0, U+1CD49, U+1CD6D) instead of "tofu" boxes — no other font on macOS but
LastResort covers these blocks.

It is regenerated by scripts/gen-symbol-font.py.
