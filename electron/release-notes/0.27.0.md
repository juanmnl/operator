**Operator 0.27.0 — terminals that keep scrolling, messages that stay in their project, and worktrees that get cleaned up.**

- **Scrollback no longer freezes on long sessions.** A lane you switched away from and came back to
  could stop scrolling up until it printed a new line, and a lane that had ended stayed frozen for
  good. The terminal now re-syncs its scroll position whenever a hidden pane's history is trimmed or
  restored.
- **Less work per line of output.** Terminal output reaches the window at most once per frame instead
  of once per read. On a measured four-lane workload that is about 155 messages a second instead of
  540.
  Typing still echoes at once: output that follows a quiet moment is sent immediately.
- **Messages stay in their project.** Every lane's session is now named `<project>--<role>`, for
  example `uwazi--design`, and lanes are told to match the project exactly. A lane in one project
  could previously reach a similarly named session in another. Reports from a session with no
  project are no longer announced to, or marked delivered for, other projects.
- **Switching back to Operator puts the cursor where you left it.** Cmd-Tab or a Dock click focuses
  the lane on screen, or the text field or preview you were typing in.
- **Worktree cleanup that actually cleans up.**
  - Leftovers that are provably not work no longer count as unsaved: an untracked copy of a file
    that is identical in the main checkout, or an old `node_modules` link.
  - A lane close that was interrupted is retried at the next launch.
  - A session from an earlier run of the app no longer blocks a worktree from being removed.
  - Settings → Worktrees has a **Rescue** action: it copies a worktree's unsaved files and a patch to
    `~/.operator/rescued/` so the worktree can be removed without losing them.
  - Branches merged by squash or rebase are labelled as merged.
  - Stray files in the worktrees folder are listed, and failures to empty the trash are logged.
- **Merge and Discard protect a running lane.** They refuse while another lane is working in that
  worktree. From a lane's own Diff panel, the lane is stopped only once the merge can go ahead, and a
  worktree that still has uncommitted files after a merge is kept. Discard asks first.
- **A lane whose checkout was deleted from outside Operator says so.** `gh pr merge --delete-branch`
  also removes any other worktree that has that branch checked out. Lanes are now told not to use
  it, and a lane left in a deleted checkout shows "checkout was removed outside Operator".
- **The side panel and rail open and close without shifting the content.** The terminal fits once,
  after the move, and the panel gives way before the console drops below 70 columns.
- **The Add agent menu opens where there is room** instead of being cut off under the header. Other
  pop-up menus use the same placement.
- **A new Infra lane** for build, CI, release and environment work, and clearer charters for Code,
  Review, Design and QA. Lanes that still carry the old default charter are updated; charters you
  edited are left alone.
