**Operator 0.26.0 — a way back out of every full-page view.**

- **Settings, Agents and Tuning now have a back control.** It sits above the page title and is
  labelled with where you came from — "Worktree overview", "All projects", a project's name, or the
  lane you were in. Pressing it returns you to exactly that, including the tab you were on. The
  Worktrees tab in particular was reachable from the home overview with no way back.
- **No back control when there is nothing to go back to.** After a reload, or on a page the app
  opened into at launch, the control is absent rather than guessing. The same applies when the
  place you came from is gone — a project you forgot, or a lane that ended while you were away.
- **Returning from project settings works.** It used to leave you on the settings page: the app set
  the destination but kept the settings page on top of it.
- **The Environment tab in Global settings lists your projects.** Environment variables are set per
  project, so this tab had nothing to edit and said so without telling you where to go. It now lists
  every project with the number of variables each one sets, and takes you straight to that project's
  Environment tab.
