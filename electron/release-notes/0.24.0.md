**Operator 0.24.0 — worktrees that clean up after themselves, a home screen for every project, and Preview you can tune.**

- **Operator opens on a home screen.** Every project is listed with its agents, its worktrees and
  the disk they use. Folders with unsaved work, folders Operator would remove, and folders whose
  repository is gone are marked. A reload of the window still puts you back where you were.
- **Project settings are named as such.** The rail entry that said `.claude` is Project settings,
  and `~/.claude` is Global settings. Environment variables for a project live there, one row per
  variable.
- **Settings → Worktrees can remove worktrees.** Folders are grouped by repository with their
  sizes. Select any of them and remove them. Folders with uncommitted changes, or commits on no
  other branch, need a second confirmation that lists them. Folders of running agents cannot be
  selected. Worktrees made before Operator recorded them are matched to their repository when git
  confirms the pairing. Nothing is removed automatically yet; the page lists what would be, and why.
- **An agent can release its worktree when it is done.** Code and Design call `worktree_done` once
  their work is committed. The folder is removed when that agent's session ends, and its branch is
  kept. Uncommitted files stop it.
- **Research, Review and QA work in the project's own checkout.** Only Code and Design get a
  worktree by default. Operator refuses to remove a project's own folder.
- **New worktrees come with their dependencies.** `node_modules` is copied with APFS cloning, so it
  takes almost no disk and tests run without an install.
- **Turning on Redlines or Inspect no longer resets the page.** They used to load a second copy of
  the page from its first address, which lost your route, scroll and app state. They now draw on
  the page you are looking at.
- **Preview notes carry a screenshot.** Annotate and Inspect notes include a crop of the element or
  area with an outline, and the agent receives it as an image.
- **CSS controls in Inspect.** Pick an element and change its padding, margin, size, colours,
  radius and opacity in place, with number fields or by dragging handles on its edges. Colours that
  match a project variable show its name. Undo and Reset work per change. Send gives the agent
  every change, before and after, with a screenshot and the component's source file when Operator
  can find it.
- **Preview grid colour.** Choose a colour and a fill strength for the layout grid, saved per
  project. The toolbar icons are drawn at one size.
- **An agent that asks you a question flashes in the rail** until you answer.
- **A coordinator's Plan tab lists the work it handed out,** with each task's lane, status and
  report.
- **Terminals no longer leave stray text behind.** Output from a hidden terminal used to be trimmed
  once it passed 512 KB, which could cut a colour code in half and put later text on the wrong row.
- **The Diff tab wraps long lines** to the panel width.
- **The Plan usage popup is tidier:** the plan line no longer clips, and no tooltip covers it.
