**Operator 0.28.3: a lane that Claude Code compacts while idle shows as waiting, not working, and the Usage and Tuning pages now include subagent spend at current prices.**

- **Idle compaction no longer makes a lane look busy.** Since Claude Code 2.1.294, a lane left idle with a long conversation can be compacted between turns. Operator read that as new work: the lane's avatar showed "compacting" for up to 5 minutes, then "working" until its next real turn, and dispatches to it were held for those 5 minutes. Now the lane reads as waiting as soon as the compaction ends.
  - This also holds when the previous turn ended without a reply from the agent, for example after Esc or a `/goal` hook.
  - Local slash commands such as `/model` no longer make an idle lane read as working.
  - A `!` shell command still reads as working until the agent replies, because Claude Code sends it to the model.
  - Compaction in the middle of a turn shows "compacting" as before.
- **Model prices match Claude Code 2.1.300.** The Usage and Tuning pages priced several current models too high. Prices are now taken from the catalog built into Claude Code:
  - Haiku 5.5 was priced at ten times its rate. Its higher rate for prompts above 100K tokens is now applied.
  - Opus 5.5 and its fast mode, Sonnet 5.5 and Mythos 5.1 were priced too high, mostly on cached input.
  - Fast mode on an Opus model outside Claude Code's fast list is billed at the normal rate.
  - Your all-time total will drop; on the machine this was tested on it went from $16,828 to $12,155.
- **Subagent spend is counted.** Turns run by subagents, forks and workflow agents are stored in separate files that Operator never read. They now count toward each session's cost and tokens, and toward the totals by model, project and effort. They do not change a lane's own turns, context, model or effort on the Tuning page.
- **Usage refreshes faster.** Transcript files that have not changed are read once per app run, so a refresh after the first one takes a fraction of a second instead of about 15 seconds. The first scan after launch takes about a second longer, because it now also reads the subagent files. The large request records Claude Code 2.1.300 adds to transcripts are skipped before they are parsed.
