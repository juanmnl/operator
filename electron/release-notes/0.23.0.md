**Operator 0.23.0 — Preview beside the Console, with a layout grid and redlines, and agents that keep talking to each other.**

> **Updating from 0.22.0: install this one by hand.** The updater in 0.22.0 has the bug this
> release fixes. Pressing "Install & Restart" there can stop every agent and leave the app open on
> 0.22.0 with nothing working behind it. Quit Operator, download the DMG below and drag Operator
> to Applications.

- **Preview can sit in the side panel, next to the Console.** Preview is a tab beside Plan and Diff.
  Choosing it in the panel moves it out of the main view, so there is one Preview per agent. The
  panel keeps the width you gave it on every tab, and double-clicking its edge splits the window in
  half.
- **The Preview toolbar fits at any width.** Its controls wrap onto a second row when the panel is
  narrow, and nothing is hidden in a menu. Interact, Annotate and Inspect are one control, so only
  one of them is on at a time.
- **A column grid over the Preview, toggled with ⌘'.** Pick Auto, 4, 8 or 12 columns, or set
  columns, gutter, margin and maximum width yourself. The grid is saved per project and follows the
  device width you preview at.
- **Redlines, toggled with ⌘⇧'.** Hover an element to see its size and its distance to its
  container. ⌥-click an element to anchor it, then hover another to measure the gap between them.
  Esc clears the anchor. The numbers are CSS pixels at the device width you chose, even when the
  page is scaled down to fit.
- **Inspect notes carry the measurement.** With an anchor set, a note about another element says
  where it sits, for example "16px below Header", so a request like "make this gap 24" arrives with
  the current value.
- **Plan usage is one cell in the bottom bar.** It shows the limit closest to its cap, and a count
  of any others at 75% or more. Clicking it opens every limit with its reset time.
- **One project's agents no longer silence another's.** The limit on how many messages an agent may
  send without a person in the loop was shared by every project's coordinator, so ordinary work in
  two projects could stop the third. It now counts each project separately. Typing into an agent's
  terminal resets its count. A stopped dispatch now shows a notice saying why, and when the message
  limit stopped it, the notice has a button to let the agent continue.
- **Old reports are no longer read out days later.** A report that waited more than 12 hours for a
  coordinator to be free is kept in the Comms log and not typed in, and a notice says how many were
  skipped. Long dispatches are no longer cut off at 2000 characters.
- **"Install & Restart" installs the update, or changes nothing.** Operator now waits until macOS
  has the update before asking to restart, and closes nothing if it never gets it. If the app has
  not quit 30 seconds after the restart begins, it quits.
