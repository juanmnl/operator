**Operator 0.28.4: idle lanes are suspended to free memory and resume where they left off, a banner offers to suspend more when the Mac runs low on memory, and the window reloads again after a renderer crash.**

- **Idle lanes are suspended.** A lane that has been idle or waiting for longer than the Tuning setting (default 30 minutes) has its Claude Code process ended. Each one held about 250 MB. The tab stays in the roster, dimmed, with "Suspended — click to resume" in its pane.
  - It resumes with `--resume` and the same model, effort and permissions when you focus it, click or type in it, or send it a dispatch or reply. The resume card and project resume bring it back too.
  - A lane is never suspended while it is working, compacting or asking, while you are looking at it, with unsent text in its composer, with a dispatch or reply waiting for it, with a dev server running, with background tasks or subagents still running, or when it is a coordinator.
  - Set the time, or turn it Off, under Tuning → Idle lanes.
  - A suspended lane stays suspended across a relaunch, and is closed like any other lane once it has been quiet past the auto-close time.
- **A banner when the Mac runs low on memory.** Operator reads macOS's memory pressure level.
  - When memory is low, a strip at the bottom of the window offers "Suspend N idle lanes". It applies every rule above except the idle time.
  - When memory is critically low, idle lanes are suspended automatically every 30 seconds, unless idle suspension is Off in Tuning.
  - The banner goes away once memory has been back to normal for a minute.
- **The window reloads after a renderer crash again.** Since 0.28.2, a crashed renderer should reload on its own. With the Preview set up, cleaning up the Preview threw an error in the main process instead: you saw "A JavaScript error occurred in the main process", the window did not reload, and dispatches to lanes were held until a restart. The crash is now logged and the window reloads.
  - The renderer crashes themselves came from memory that grows by about 30 MB an hour until the renderer runs out, after three to four days. That growth is not fixed in this release.
- The window is titled "Operator".
