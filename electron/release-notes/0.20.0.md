**Operator 0.20.0 — the effort you set is the effort your agents run at, and the orb finally says what a lane is running.**

- **"Normal" was never a real effort level, and Claude Code was silently throwing it away.** The
  app offered High, Normal and Low; the CLI accepts Low, Medium, High, Extra high and Max, and it
  discards anything else without an error. Two of the default agents — Operator and Design — ship
  set to Normal, so they have never once run at the effort the interface claimed. The ladder is now
  the real one, existing agents set to Normal are migrated to Medium rather than quietly promoted,
  and Extra high, which Anthropic recommends for coding work, is selectable for the first time.
- **Starting an agent no longer rewrites your machine-wide Claude Code settings.** Each launch wrote
  that agent's effort into your global `settings.json` before spawning, so starting six agents at
  six different efforts left whichever went last deciding for all of them — and left your own
  default overwritten afterwards. Effort now travels with the agent it belongs to, and changing it
  on a running agent takes effect on that agent instead of moving everyone else's.
- **Hovering an agent's orb shows what it is running.** Model and effort, in both the narrow and
  wide sidebar. Where the model actually answering differs from the one the agent was launched with
  — an agent started on your account default, or switched mid-session — both are shown and labelled,
  because a confident wrong answer is worse than two honest ones. Effort is always marked as what
  was asked for: nothing observes it.
- **Sonnet usage was over-reported by half.** Sonnet 5 costs less than the generation before it, and
  the cost view still billed every Sonnet session at the older, higher rate. Cache reads are now
  priced per model too, rather than as one fraction of the input rate that happens to be wrong for
  the newest frontier model — and since an agent session is mostly cache traffic, that is the
  correction with the most room to matter.
