**Operator 0.22.0 — the Dock badge is yours again, the prompt is where you left it, and agents restart when Claude Code updates.**

- **A previewed app can no longer badge Operator's Dock icon.** Any page shown in the Preview pane
  runs inside Operator's process, so a project that sets an app badge, as mantel does with its
  pending reservations, was badging Operator instead. The Badging API is now a no-op for previewed
  content in the Preview frame, the inspect view, and any service worker they register. A stale
  badge is cleared when the app starts.
- **Switching to an agent opens at the bottom, with the prompt on screen.** A pane reactivated
  after a long turn could sit scrolled above the fold, and the prompt row, always the last line, was
  what fell off. Activation now parses the output buffered while the pane was hidden at the width
  it was written for, then fits the terminal, then scrolls to the bottom.
- **Scrollback that is empty after a long session is Claude Code's doing, not Operator's.** Once
  Claude Code's own frame grows taller than the terminal it repaints only the last screenful using
  cursor moves, so those lines never reach the terminal's history. The fullscreen TUI mode in
  Preferences is the one setting that avoids it.
- **Restart an agent when Claude Code has updated underneath it.** Claude Code updates itself in
  the background and a running agent keeps the old binary, showing its own "Update installed ·
  Restart to update" banner. Operator now records the binary version an agent started on, watches
  the installed one, and shows a "Claude Code X available · Restart" chip on the agent's header,
  in the project's ⋯ menu, and in ⌘K. Restart is enabled only between turns. It resumes the same
  conversation in the same worktree and rail slot, and dispatches keep reaching it afterwards. A
  preference, off by default, restarts idle agents on its own, one at a time.
