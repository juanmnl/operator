**Operator 0.25.0 — Preview shows Electron apps.**

- **Preview can show a running Electron app.** Switch Preview's source to Electron app and pick a
  window. The app is shown live, and clicks, scrolling and typing reach it. ⌘ shortcuts stay with
  Operator.
- **Inspect, Redlines, the grid and CSS controls work on the Electron app too.** Picks, measurements,
  note screenshots and style changes behave as they do for a web page.
- **The app has to open a debugging port once.** Each lane has its own port in
  `OPERATOR_CDP_PORT`. In the app's main process, for development builds, add
  `app.commandLine.appendSwitch('remote-debugging-port', process.env.OPERATOR_CDP_PORT)`, or start
  Electron with `--remote-debugging-port`. Anything on this Mac can control an app with that port
  open, so keep it out of release builds.
- **A development build of Operator started from a lane can be previewed from that lane.** Packaged
  builds never open the port.
- **Limits:** one attached app at a time, shown at its own window size (device widths do not apply),
  and only its windows, not its Node main process.
