**Operator 0.21.0 — fewer surfaces, honest ports, and the numbers that tell you what to tune.**

- **The Chat and Files views are gone.** Console and Preview remain. The two views were not used,
  and removing them takes out about five thousand lines, a code editor dependency, and ⌘J. The
  model and effort of a running agent are now changed from chips on the session toolbar, enabled
  only between turns so a click can never land on a permission prompt.
- **A dev port is handed out only after it is proved free.** The allocator now binds the port,
  checks the lease file, and shares a directory's port with a second agent only when the server on
  it is provably one of ours. Two agents starting at once can no longer take the same port, and the
  reservation is no longer released while a sibling still serves on it, which is how two agents in
  different projects ended up told to use the same port.
- **Dev servers that outlive their agent are found and closed.** A server an agent started in the
  background used to survive the agent forever, holding its port. Closing an agent now reaps it, a
  ten-minute sweep catches servers whose agent closed while the app stayed open, and a Dev servers
  list in Worktrees preferences shows everything else by owner, killed only on your confirmation.
- **Remote Control is on for each project's operator only.** Claude Code now registers every session
  with the phone app by default. Operator writes the choice per agent, on for the operator role and
  off for the rest, with a per-role toggle, and names the session after the project.
- **A Tuning page, in place of the old usage view.** Every number sits next to the change it argues
  for: which agent spends most by model and effort and the one step down that would move it, which
  project dominates the week, compaction pressure per agent, tool output size, and cache efficiency.
  Tokens are the headline; cost is the footnote. Effort and compactions are now read from the
  transcript, and the compacting state is finally reported instead of never.
- **The plan reading moved to the session's bottom bar, with the session's context.** Context used
  of window with the compaction count, model and effort, and the three plan limits named in words
  with the one that will stop you marked. The rail keeps a text reading when no session is open.
- **Agents that report done close on their own.** A report now counts as finished, so an agent that
  hands its work back is closed after the keep-warm window instead of sitting for two hours.
- **Close a project from the rail.** A ⋯ on the project row opens the same menu as right-click, and
  the row shows it is closing while the agents shut down.
- **Agents can hand work to each other over Claude Code's own session bus.** `dispatch` and `reply`
  are MCP tools now: Operator decides the route, holds a non-operator's dispatch for your approval,
  and the agent sends the message itself and gets a real delivery result. The sentinel lines keep
  working for this release.
